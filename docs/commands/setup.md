# Setup

***OctoTrack*** has commands to help you make sure it is functioning properly, and all the necessary files and folders are there.

Running `octotrack setup` automatically sets up the necessary files / folders OctoTrack needs to function. If you ever forget to run this, OctoTrack will throw an error message reminding you to.

If you messed around with app data, or just decide not to use OctoTrack anymore, you can check the setup with `octotrack setup validate` or remove it with `octotrack setup remove`.

??? warning
    Running `octotrack setup remove` will clear your GitHub Auth Token!

??? note "Got Ideas?"
