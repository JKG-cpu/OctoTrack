# Commits

***OctoTrack*** has a command for grabbing commits from a GitHub Repository.

By default, OctoTrack only shows the first 10 commits, but you can pass an argument *(`--all`)* to view all the commits from a repository.

```bash
octotrack commits show <owner/repo> --all
```

This then renders a neat list of the commits in a Repository, as well as the committer and the date.
