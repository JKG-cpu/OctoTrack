# Contributing

OctoTrack is a small personal project, but contributions are welcome if you'd like to pitch in — bug fixes, new commands, docs improvements, whatever you're interested in.

## Getting started

1. Fork the repo and clone your fork.
2. Install dependencies with [`uv`](https://docs.astral.sh/uv/):

   ```bash
   uv sync
   ```

3. Make your changes.
4. Run the test suite before opening a PR:

   ```bash
   uv run pytest
   ```

## Opening a PR

- Keep PRs focused on one change where possible — easier to review, easier to merge.
- If you're adding a new command or fixing a bug, a quick test covering it is appreciated but not required.
- Not sure if an idea is a good fit? Open an issue first and we can talk it through.

No formal process beyond that — just be reasonable and it'll probably be fine. Thanks for considering contributing!
